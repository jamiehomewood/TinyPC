# TinyPC

A 360° scenario for the Igloo immersive room: you're a few millimetres tall, standing on the motherboard inside a desktop PC. Built with Room Builder and Tour Builder (`jamiehomewood/SpoutyRoomBuilder`).

| Folder | Contents |
|---|---|
| `docs/` | Spec, playbook, errors log, facilitator notes |
| `specs/` | Scene specs (JSON) |
| `tours/` | Tour Builder tours + `audio/` |
| `models/` | Part models (GLB) + `credits.md` |
| `renders/library/` | Finished Room Builder library entries |
| `tools/` | Model scripts, sync batch files |

Renders, models and audio are stored with Git LFS.
